4. OPEN PORT ANALYSIS
----------------------------------------------------

Port 135: Microsoft Windows RPC

Microsoft Windows RPC uses port 135 for communication between windows components and aplications. Exposing RPC services unnecessarily can increase the system attack surface. Open port does not necessarily mean that the system vulnerable, security depends on specific RPC services, firewall configuration, patch level etc.


Port 445: Microsoft-DS/SMB

Microsoft SMB services used port 445 for file and printer sharing and windows network communication. If exposed to untrusted networks, it can increase the attack surface and can pose serious security vulnerabilities


Port 8254/tcp: PremiereOpinion-related services

Nmap identified this service a unknown, but on further investigation using windows powershell, it showed that the this port is associated with pmropn.exe process from PremiereOpinion. The service is listening on localhost. Therefore, it has limited exposure to network and not directly listening on external network interfaces.


Port 8888/tcp: PremiereOpinion service

Nmap identified an uncertain service and detected an HTTP-like response. Further investigations showed that the port belongs to pmservice.exe process, associated with windows service named PremiereOpinion. The service is listening to 0.0.0.0 which means it can listen to all local IPv4 interfaces. The service needs to be reviewed and restricted if not required.

----------------------------------------------------
6. CONCLUSION
----------------------------------------------------

The Nmap assessment identified four open TCP ports on the
local Windows 11 system: 135, 445, 8254 and 8888.

Ports 135 and 445 are associated with Windows networking
services, while ports 8254 and 8888 are associated with
PremierOpinion software.

Port 8254 is bound only to localhost, while port 8888 is
configured to listen on all IPv4 interfaces and therefore
warrants additional access-control review.

The scan does not by itself establish that any of the
identified services are vulnerable. Reviewing unnecessary
services, firewall rules, software updates and network
exposure can help reduce the system's attack surface.
