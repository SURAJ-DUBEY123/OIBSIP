 OASIS INFOBYTE Cyber Security Internship — Task 4

 Research Report: Common Network Security Threats

This task focuses on researching common network security threats, understanding how they work, their real-world impact, and the mitigation strategies used to defend against them.

 Threats Covered

The report covers the following network security threats:

- DoS/DDoS Attacks
- Man-in-the-Middle (MITM) Attacks
- IP Spoofing
- DNS Poisoning/Spoofing

 Report Contents

The research report includes:

- Introduction to network security threats
- Technical explanation of each attack
- Real-world attack examples
- Security impacts
- Specific mitigation strategies
- Comparison table of the threats
- Key takeaways for network administrators
- Credible references
